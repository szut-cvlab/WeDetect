# 低空域 OVD：方法

底座：WeDetect 双塔无融合、对比头点积分类、FPN 多层预测、文本塔编码类名。方法创新只动文本侧与打分侧，视觉塔与检测头结构不动，这样域适配微调配方可直接沿用。

## 1. 病根与调研结论

### 1.1 尺度病

同一类跨飞行高度尺度差几十倍，一个类名一个 embedding 对所有尺度。

| 结论 | 依据 |
| --- | --- |
| CLIP 置信度结构性混入尺度偏差，小目标分数系统性偏低，无参温度校正即可显著提升小目标召回 | arXiv 2607.10993（Confidence Scores in OVD Are a Biased Mixture of Scale and Semantics，2026-07） |
| 高空小目标靠切图缓解是工程共识，但切图只解决分辨率不解决"打分对不齐"，方法层仍有空位 | SAHI arXiv 2202.06934；altitude-aware tiling arXiv 2511.19728；WeDetect 摸底：Tiny@1280 在 VisDrone AR@.5 49.1、AP@.5 只剩 15.9，丢分在打分不在定位 |
| 现有低空 OVD 工作（LAE、DisDop、OpenRSD、DisDop 2605.24639）全部走"域先验蒸馏/对齐"路线，没有做尺度条件化编码 | DisDop：RemoteCLIP+DINOv3 多级先验蒸馏进轻量检测器；OpenRSD 2503.06146：开放 prompt 对齐遥感域 |

### 1.2 组合词病

训练见过 boat 查不出 fishing boat，整词编码没见过就是瞎猜。

| 结论 | 依据 |
| --- | --- |
| CLIP 类组合泛化差是公认事实，语言侧分解是主要解法 | arXiv 2403.18525（语言主导 CLIP 对象-属性组合泛化）；arXiv 2502.18326（组合泛化需要指数级预训练频率） |
| 检测侧已有层级 embedding 工作：SHiNe 用类树 Is-A 句子融合父类 embedding 成 nexus 向量，training-free，iNatLoc +31.9 mAP50 | arXiv 2405.10053（SHiNe，naver，代码公开） |
| 软提示分解（属性 soft prompt × 对象 soft prompt）在组合零样本里有效，但都做在分类不做检测 | CSP arXiv 2204.03574；VAPCZSL arXiv 2502.20292 |
| 细粒度开词表分割已出现"分解对齐"（属性与类别分开编码再组合），与本工作 5.2 思路同源，检测侧还没有 | arXiv 2605.15942（Decomposed V-L Alignment for Fine-grained OVS，2026-05） |
| 层级蒸馏进检测器已被验证能同时提 base 与 novel | HieraVLDistill arXiv 2203.10593；HSDF arXiv 2503.10152 |

## 2. 对原设想 5.1 / 5.2 的评审

- 5.1 `e_l = e + Δ_l`：方向对，但 per-FPN 偏移是最弱形式——推理时同一类各层各出一份 embedding 没问题，可训练时一层一个 Δ 数据量少、容易过拟合成每层的常数 bias。升级为尺度条件化：Δ 由候选框的实际尺度（log 边长）或 tile 内相对尺度经小 MLP 生成，训练用 GT 尺度监督、推理用候选尺度，等价于把"这个尺度该用什么模板"显式建模。
- 5.2 `e = e_head + W·e_attr`：结构可行，与 CSP/2605.15942 同构但检测侧没人做，是卖点。风险是拼回去的向量丢细粒度（fishing boat 与 sailing boat 混淆），必须配层级对比监督（子类近父类、兄弟比到父类更远），这一条设想里已写，保留。

## 3. 技术路线

按优先级，全部只动文本塔输出与打分侧：

### 3.1 尺度条件化类名编码（对应 A 篇 5.1）

1. 每类基础 embedding `e`：文本塔按底座配方全参跟训（lr_mult=0.01，不冻结），178 类文本前向每步重算，<10ms 可忽略。
2. 尺度编码器：输入 `s = log(候选边长 / 1280)` 与 FPN 层级 `l`，小 MLP 输出 `Δ(s, l)`，分类向量 `e' = e + Δ`。
3. 训练监督：正样本 GT 边长产生 `Δ_gt`，负样本用 IoU≥0.1 的错类框；再加拉力约束——同一类不同尺度的 `e'` 之间互为正对（跨尺度一致性），不同类推开。
4. 推理：检测头每层候选带尺度，生成各自的 `e'` 打分，NMS 后取最高。
5. 退路：若 MLP 版不稳，退回 per-FPN `Δ_l`（原 5.1），论文里作为消融对照。

### 3.2 层级组合类名编码（对应 A 篇 5.2）

拆词表已生成：`data/coco_anno/vocab_compound_map.json`（59 类 = 46 多词类 + 13 复合词，如 `jetski = jet + ski`）。

1. 组合编码：`e = e_head + W·e_attr`，W 低秩可学；单词类（sedan、boat）即 head 本身，不拆。
2. 层级对比监督：子类近父类、兄弟间距大于到父类；损失加在 178 类全表，每步重算（一次文本前向，<10ms），与图像 batch 无关。
3. 检测监督即常规检测损失：正类来自本图标注，组合类现拆现拼，不用造数据。
4. 推理外推训练未见组合，报 novel 组合短语分——B 篇留出细类短语的入口。
5. 与 3.1 正交叠加：`e' = e + W·e_attr + Δ(s,l)`。

| 规模 | 数值 |
| --- | --- |
| 兄弟中心词组 | truck 8 / sign 7 / boat 3 / ship 3 / car·chair·light 各 2 |
| COD 组合词框 | 8,282（box truck 2,758、dump truck 990、cabin cruiser 709） |
| FOD 组合大类 | freight car 2.3 万、awning tricycle 4,377 |

### 3.3 打分侧免训练修正（动机实验，不占方法主线）

- 现象：OVD 置信度不可信——同为正确检出，分数随目标变小被系统性压低（2607.10993）。
- 量化方法：主证据为 TP（IoU≥0.5 配上的检出）按边长分档的均分，打分公平则各档持平；佐证为 AP@.5/AR@.5 比值——AR 只计配上 GT 的比例，AP 额外要求正确检出按分数排序时位于误检之前，比值即正确检出中排得上号的份额（分档 AP/AR 为 COCO 原生输出，比值为本文构造的诊断量）。
- 实测（Tiny@1280，VisDrone）：

| VisDrone | <16 | 16–32 | 32–64 | ≥64 |
| --- | ---: | ---: | ---: | ---: |
| TP均分 | 0.032 | 0.079 | 0.136 | 0.233 |
| FP均分 | 0.007 | 0.013 | 0.019 | 0.019 |
| AR@.5 | 23.5 | 52.2 | 69.3 | 77.8 |
| AP@.5 | 5.0 | 13.9 | 22.7 | 32.7 |
| AP@.5/AR@.5 | 0.21 | 0.27 | 0.33 | 0.42 |

TP 均分跨档差 7.3 倍而 FP 均分近乎持平，定位（AR 23.5%）不缺、排序（比值 0.21）塌——丢分主要在打分侧，不在定位侧，与切图/分辨率路线无关。

- 修正方法：在 ovd_val（3,030 图，非考卷）推理，每个检出记录 logit `z=ln(s/(1-s))`、边长桶、TP 与否；每桶一维搜索 T 使 `BCE(σ(z/T), y)` 最小，推理时按桶替换分数，不动权重。脚本 `eval/scale_calib.py`，T 存 `work_dirs/scale_calib_T.json`。

| ovd_val 拟合 T_b | <16 | 16–32 | 32–64 | ≥64 |
| --- | ---: | ---: | ---: | ---: |
| T_b | 0.91 | 0.94 | 0.92 | 0.81 |

| 套用后 | AP@.5:.95 | AP@.5 |
| --- | --- | --- |
| VisDrone | 9.4→9.4 | 15.9→15.9 |
| MOBDrone | 19.8→19.9 | 39.3→39.9 |

- 结论：T 对边长非单调，套用后考卷变化 ±0~+0.6——小目标 TP 与同尺度 FP 的分数分布交叠，整桶提升分数则误检同升，排序不变。打分侧的尺度偏差无法由事后单调变换修复，根源在视觉-文本表示几何，据此引出 3.1 的尺度条件化编码。
- 本实验的作用（不是证明"小目标弱"，那是通识）：① 丢分拆账——框能开（<16 档 AR@.5 23.5）但排不上（比值 0.21），丢分大头在打分侧而非定位侧，排除"应走切图/提分辨率"（SAHI 路线）的替代解释；② 低成本修法排除——分数事后校准是 OVD 现成标准手段，实测无效才能论证必须改模型内部（3.1），否则等于没排除过工程捷径。

### 3.4 域适配（底座已定，方法侧不动）

1280 输入切片训练、文本塔 lr_mult=0.01 跟训不冻结、全冻做对照。`ovd_train.json` 训练 `ovd_val.json` 验证。

## 4. 实验设计（对应 A 篇第 6 节）

训练顺序：先训纯域适配底座（主 baseline），再训完整方法，消融即各配置相对底座/完整方法的对比。

| 配置 | 构成 |
| --- | --- |
| 底座 | WeDetect 在 `ovd_train.json` 纯域适配（1280 切片、文本塔 lr_mult=0.01 跟训），全冻做对照；**一切后续实验的载体** |
| +3.1 | 底座 + 尺度条件化 Δ(s,l) |
| +3.2 | 底座 + 层级组合编码 |
| 完整 | 底座 + 3.1 + 3.2：`e' = e + W·e_attr + Δ(s,l)`，主结果报这行 |

消融：上表四行互比即主消融（各创新点的单独与叠加增益）；方法内变体另加——Δ 退 per-FPN `Δ_l`、去层级对比、去 W 低秩（只拆词）、3.3 温度校正单独。

| 专项 | 内容 |
| --- | --- |
| 动机实验 | 3.3 温度校准，在底座模型 + `ovd_val.json` 上分桶拟合与验证，出"尺度偏差存在且轻量校准修不完"证据 |
| novel 类 | MOBDrone test 的 `surfboard` / `lifebuoy`（train 段零样本）按 novel 类报 AP |
| novel 组合探针 | 基于 +3.2 模型：考卷 GT 框不变，类名换成训练未见组合短语（boat→fishing boat 一类），报分数降幅——B 篇语义四级探针的入口；探针短语考卷无 GT，不报 AP |
| 外部对照 | WeDetect 零样本、GDINO、YOLO-World 在两考卷直接推理，零训练参考线 |

报分口径：两考卷均报总 AP + 目标边长四档（<16 / 16–32 / 32–64 / ≥64px）分档 AP。

## 5. 与已有工作的差异声明（写 Related Work 用）

| 工作 | 他们的路线 | 我们的差异 |
| --- | --- | --- |
| LAE-DINO / DisDop / OpenRSD | 补域差：域内数据训底座、蒸馏遥感基础模型先验 | 类名向量仍是每类一个静态 embedding；我们把向量做成随尺度（Δ）与词结构（W）变化的函数，与他们的域对齐正交、可叠加 |
| SHiNe | training-free：类树 Is-A 句子融合父类向量，无学习 | 我们 W 低秩可学 + 层级对比监督，训练未见组合可外推 |
| CSP / Decomposed V-L Alignment (2605.15942) | 分类/分割侧拆属性软提示 | 检测侧没人做；且与尺度条件化联合 |
| SAHI 系切图 | 推理侧切块工程 | 文本侧方法与切图正交，可叠加 |
