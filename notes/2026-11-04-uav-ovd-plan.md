## 动机

### 数据的病

- 通用底座没在低空训过。WeDetect 在 VisDrone 零样本 AP 9.6，同一个权重在 COCO 上是 44.9。
- 低空至今没有按 OVD 协议评测过的工作。LAE 和 DisDop 的评测集本身就是训练源，CastDet 用已弃用的 GZSD 协议。
- 已有的低空标注集词表窄。VisDrone 10 类，UAVDT 3 类，覆盖不了开放词表。
- LAE-1M 是遥感那边最大的训练池，域偏卫星和高空，它的 COD 那路按面积取 top-K 候选，小目标系统性丢弃，框还靠 SAM 出、不紧。低空最需要的恰恰是小目标。
- 无标注低空影像不少，WebUAV 的视频帧、SkyFind 的爬取帧、各家跟踪集，但没有管线把它们做成合格的 OVD 训练数据。
- 考卷是缺的。没有 4K 原帧、目标大小和场景可控分层、并且包含训练池没收过的类的评测集。已有数据集的类名跟训练池大量重叠，同源的 train 图还进过训练池。

### 方法的病

- 对齐层丢分：候选能盖住 30.6% 的 GT，最终 AP 只有 9.6——框找到了，类名打分把大半丢了。这不是分辨率问题，是双塔点积在低空小目标区域上跟文本 embedding 对不齐。
- 尺度跨度：同一类在不同飞行高度下尺度差几十倍，一个类名 embedding 去匹配所有尺度，天然吃亏。
- 无融合双塔把每个类名编成独立 embedding，属性和关系不可组合，细类判别也弱。低空词表偏偏靠层级，训过 boat 要能查 fishing boat。

## 数据

### 切图

- 切在标注之前，只看图像宽高，不看目标。训练池和自建评测集同用一套规则。
- 长边 ≤ 2560：不切，整图进池。2560 = 1280×2，缩放比 2 以内 16px 目标缩后剩 8px，贴住 P3 stride=8 召回下限。
- 长边 > 2560：**块尺寸固定 1280×1280，先算块数，再算步长**。横竖各算一遍：
  - 块数 `n = ceil(边长 / 1280)`
  - 步长 `stride = (边长 - 1280) / (n - 1)`，起点 `0, stride, 2*stride, …`，末块自动贴右/下边界
  - 边长不是 1280 的整数倍时，相邻块自然重叠 `1280 - stride`，重叠是设计的一部分，不是要消掉的东西
  - CODrone 3840×2160：横 n=3、stride=1280（起点 0/1280/2560，不重叠）；竖 n=2、stride=880（起点 0/880，重叠 400）→ 6 块，每块 1280×1280
  - 4096×2160：横 n=4、stride=938.7（起点 0/939/1877/2816，重叠 341）；竖同上 → 8 块，每块 1280×1280
- **标注归属只看中心：中心落在块内就写这个块**，框按块边界裁剪，裁完小于 4px 的丢弃。中心落在重叠带里的，那几个块各写一份。
- Qwen3-VL 原生动态分辨率，像素预算默认上限 16,777,216（= 4096×4096），4K 整图在预算内；粒度 1 token = 32×32 像素（patch 16 × merge 2）。

#### COD：无标注图扩词表

图源**只有 SkyFind**：全量 35,599 图剔四域（VisDrone 4,688、DroneVehicle 4,829 与 FOD 重复，SeaDronesSee 3,671 + MOBDrone 1,065 整集留作考卷二），剩 21,346 张再做同帧去重 → **15,432 张**，清单 `SkyFind/cod.json`，下游只读它。

它的框一概不用（UAV REC 基准，bbox 只覆盖被表达式提到的目标，非穷尽）；图只当 COD 帧源。衍生物属 cc-by-nc-nd-4.0，只自用训练，不进发布包。

其余候选已逐个查过并排除，不再评估：UAV123（仅 123 序列、要自抽帧 14 GB）、WebUAV-3M（原视频 819 GB）、GeoText-1652（单一校园、512×512）、ERA / CapERA（事件分类帧，时间冗余高）。

#### 管线修正

管线对 LAE-COD 的修正：

- 改用 WeDetect Uni 全召回。摸底已验证大中目标召回可用，16px 以下靠切片推理补。
- 改用置信度分层，高分直接收，低分人审。16px 以下档全人工过。
- 每条框让 VLM 输出 `coarse / mid / fine` 三段（受控自由文本，允许留空或与上位重复），不止单个类名。三段汇总去重成层级表，人工只审冲突项；同一套字段派生诊断协议的语义四级探针。
- FOD 补标分两轮。第一轮用 Uni objectness 全召回扫 FOD 图（类别无关，不依赖文本塔认新词），留下高分但匹配不到 GT 的框，VLM 命名加人审后补标或丢弃；第二轮见步骤 7。补标后 json 要能区分原生框与补标框，残余漏标率靠抽样人审估。

公开集这条线的量级是 1.6M 到 7.8M 图，词表落在 365 类到 150K 名词短语之间，都用于大池预训练；域适配不需要这个量级。

两种训练范式对标注的要求：

- GDINO 式文本输入有两种：检测数据是整表类名拼成一句，指代数据是一条描述配它提到的若干框
- YOLO-World 式训练不预置词典，在线词表按 batch 现建，正类来自本 batch 标注，负类从数据集类名池采样，上限 80；预置只发生在推理

| 范式 | 文本组织 | 词间交互 | 词表上限 | 漏标后果 |
|---|---|---|---|---|
| GDINO 式（深度融合） | 类名拼成一句 | 有，类名之间互相影响 | BERT 256 token | 提到的类没框即假负 |
| YOLO-World 式（双塔） | 每类独立编码后点积 | 无 | 任意大，一次前向算完 | 同上 |

我们的标注预算按双塔这条算：凡进 batch 正类的词，每图实例都要框全。

词表不用提前定。WeDetect 的做法是先做类别无关召回（objectness 检测器）拿到所有框，再让 VLM 自由命名加拒识，词表是标注的产物；训练时正类是本图标注（多粒度取最细一级），负类来自滚动队列：`enrich` 把队列里不属于本图正类的词追加到该图文本列表（`weref.py:38-44`），`update` 再把正类并回队列、超 80 随机保留（`wdscoco.py:157-159`）。所以漏标的控制点在框召回是否穷尽（加人审兜底），不在词表对齐。要提前定的只有两处：FOD 已有类名的合并去重与漏标审计，评测时的官方类名表。

- 类名沿用 `coarse / mid / fine` 三段。图与标注全公开，协议声明评测集不得进训练池。

### 诊断协议

- 分层报分，不混总 AP。目标大小四档，按边长算：16 以下、16–32、32–64、64 以上像素。再按类别常见还是稀有、按不同评测集分开算。
- 尺度偏差：每模型每考卷按目标边长分四档，报分数与 log 面积的斜率、相关系数、每档均值。
- 语义偏差：同一图同一框，类名四级由具体到笼统（fishing boat、boat、vessel、object），报分数降幅。
- 训练见过和没见过的词分开报。
- 图内不存在的探针类，报误报率。
- 三个以上模型同口径跑，统一阈值，禁止 per-class 阈值。
- 量法和代码随论文发布。

1. FOD 整形：**已完成**（五集 118,757 训练样本 / 1.97M 实例，产物见数据笔记 §2.1.0）。剩词表合并去重一步。

4. 自建评测集：pexels 4,462 帧筛到 3–5k 张可标场景，预标，人审补漏，二轮审计。
5. 归属划分：**已定**（排除表与 §2.1 判据）。SeaDronesSee 和 MOBDrone 整集只评测，VisDrone 的 train+val 进训练池、test-dev 只评测。进池的其余各集按 FOD 表口径处理（DroneVehicle 只用 RGB 半边，ATR-UMOD 的红外半边已删，本地只剩 RGB；CODrone 与 ATR-UMOD 的 OBB 转水平框；CODrone 与 HazyDet 的 4K 按 §切图切块）。不进池的集与其理由见上方排除表。

9. 对比：零样本大模型 WeDetect、Grounding DINO、YOLO-World，对域适配底座，同口径分层对比。

## 论文结构

两篇：A 篇投 CVPR/ICCV，B 篇为其 TPAMI 扩充。

### A 篇（CVPR/ICCV）

1. Introduction：低空 OVD 空位；两条病，同一类跨高度尺度差几十倍、组合词没见过查不出。
2. Related Work：OVD 三范式、遥感 OVD 与「标题低空证据高空」、UAV-OVD 一类工作。
3. 诊断与评测口径：留出协议、分层报分、尺度偏差与语义偏差量法、探针类误报。
4. DroneOVD-2M 数据引擎：切图规则、Uni 全召回加切片加 VLM 层级标签、置信度分层人审、统计与标注成本、发布范围（训练集与评测集图像标注全公开，声明评测集不得进训练池，不设服务器）。
5. 方法：
   - 5.1 尺度条件化类名编码：每层 FPN 各用 `e_l = e + Δ_l`，`Δ_l` 按层级学习。
   - 5.2 层级组合类名编码：训练没见过的组合词（fishing boat）查不出，因为整词编码没见过就是瞎猜。把词拆成中心词（boat）和修饰词（fishing），分开编码再用一个学出来的低秩矩阵拼回去，`e = e_head + W·e_attr`。拼法用词表层级当教材：子类向量要靠近父类（查 boat 能召回 fishing boat），兄弟类之间要比各自到父类更远（fishing boat 不把 sailing boat 认成同一个，但不飞出船的范围）。层级表来自 COD 标注的 coarse/mid/fine 三段汇总去重加 FOD 类名补齐，人工审一次冲突项，不逐图标注。视觉塔不动。
6. 实验：域适配设置；主结果分层报分；留出类与留出细类短语；消融（去掉 `Δ_l`、门控两项拆开、只拆词不加监督）；跨域 SeaDronesSee 与 MOBDrone。

### B 篇（TPAMI 扩充）

2. Related Work：OVD 基准（LVIS、ODinW）、遥感 OVD 与「标题低空证据高空」、既有低空数据集。
